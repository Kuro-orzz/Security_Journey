# Security Journey

> Ghi chép hành trình học và nghiên cứu bảo mật — từ CTF đến thực chiến.

## Về blog này

Đây là nơi mình ghi lại quá trình học, nghiên cứu và thực hành bảo mật. Nội dung bao gồm:

- **Web Security** — khai thác và phòng thủ ứng dụng web
- **CVE Analysis** — phân tích lỗ hổng thực tế, review PoC, tìm hiểu root cause
- **CTF Writeups** — lời giải và bài học từ các cuộc thi Capture The Flag
- **Investigation** — các case đang điều tra
